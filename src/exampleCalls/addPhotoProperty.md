### EXAMPLE ADDING A NEW PROPERTY TO PHOTO

URL to use: `https://slider-fun.onrender.com/api/photo/addProperty/:id`

```
{
    "name": "Grayscale",
    "property": "grayscale",
    "value": 0,
    "range": {
    "min": 0,
    "max": 100
    },
    "unit": "%"
}
```

Note: This call will add this `Grayscale` property to the photo's `photoProperties` list
